# MiTuto-R

Juego web familiar de práctica escolar para Primaria.

## Asignaturas y cursos actuales

| Asignatura | Curso | Actividades |
|---|---:|---|
| Lengua | 1.º | Lectura inicial, copia de palabras y ahorcado |
| Lengua | 3.º | Sinónimos y antónimos, lectura comprensiva y dictado |
| Ciencias Sociales | 3.º | Tarjetas mezcladas: completar huecos, selección, señales de tráfico y examen combinado |
| Ciencias Naturales | 3.º | Seres vivos e inertes, cinco reinos, animales, ecosistemas, relaciones entre seres vivos y relaciones alimentarias; completar huecos, selección, clasificación, ordenación y examen combinado |

La aplicación conserva un progreso independiente por `asignatura + curso` en el navegador.

El bloque de Ciencias Naturales incorpora los esquemas aportados de 3.º de Primaria sobre relaciones con otros seres vivos y relaciones alimentarias: ecosistema; familia, sociedad y bandada; mutualismo, comensalismo y depredación; productores, consumidores, descomponedores y la cadena alga → camarón → sardina → bacalao.

El Tema 3 de Lengua incorpora las fichas aportadas sobre textos literarios y no literarios, prosa y verso, poema, verso, rima, comparación y metáfora.

## Repaso adaptativo local

Cada respuesta correcta o fallada se registra solo en el navegador, por pregunta y destreza. El botón **«Repasar lo que cuesta»** muestra las paradas nuevas, en práctica o consolidadas y abre la más débil; en las estaciones de tarjetas mixtas, las actividades con más fallos aparecen primero. No hay cuenta, analítica ni datos enviados fuera del dispositivo.

El contenido de Ciencias Sociales se limita a los seis esquemas curriculares aportados para 3.º de Primaria. Alterna tarjetas de respuesta escrita y selección para practicar en orden diferente en cada intento; la señal triangular de peligro con dos niños se ha incorporado a partir de la ficha de seguridad vial. No existe una segunda web separada.

## Publicación

La web se publica desde la rama `main` mediante GitHub Pages.
